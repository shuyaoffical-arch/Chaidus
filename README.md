# Chaidus — personal website

A full-page personal site with a nostalgic blue title bar, warm beige panel, a home page, and a weekly blog.

## Customize it

- Change `Your Name` in `index.html` and the blog HTML files.
- Replace `profile.svg` with `profile.jpg`, then update the `src` value in `index.html`.
- Change the blue and beige colors in `style.css` near `:root`.
- Add weekly posts by copying `blog/hello-world.html`, then add each link to `blog/index.html` and the home page.

## Publish with GitHub Pages

Settings → Pages → Deploy from a branch → `main` → `/(root)`.
